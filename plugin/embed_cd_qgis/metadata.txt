about=Generates year-over-year land change maps from AlphaEarth satellite embeddings (Google Satellite Embedding V1), which cover the whole globe for every year 2017-2025 at 10 m. Works tile by tile and fills the canvas as each tile completes, so memory stays flat and large areas are possible. Missing data is shown as its own class, never as "no change". CPU-only, nothing to train, no account or API key — data is read directly from public cloud-optimized GeoTIFFs. No installation steps on Windows: GDAL, numpy and scipy ship with QGIS. The one-time tile index is Parquet, read with pyarrow or with GDAL's Parquet driver, whichever your QGIS has; some Linux builds have neither and need 'pip install pyarrow' once. Tested on QGIS 4.0.1; 3.28+ should work but is untested. The AlphaEarth Foundations Satellite Embedding dataset is produced by Google and Google DeepMind (CC-BY 4.0).
